# AGENTS.md

## Stack and Commands

This is a Nuxt 4 / TypeScript admin UI managed with pnpm.

```bash
pnpm dev
pnpm build
pnpm lint
pnpm typecheck
pnpm test
pnpm link:local          # use sibling catalog and image API TypeScript packages
pnpm unlink:local        # restore packaged API dependencies
```

Do not edit `.nuxt/` or `.output/`. Keep real values in ignored `.env`; only non-secret defaults
belong in `.env.example`.

## Structure and Boundaries

- `app/` contains pages, components, composables, schemas, and client UI.
- `server/api/` is the Nitro BFF boundary; browser code calls local `/api` routes.
- `server/utils/catalog-client.ts` and `server/utils/image-client.ts` own server-side Connect
  clients. Do not construct transports in route handlers.
- Preserve bearer-token forwarding and tenant-header propagation in those client helpers.
- Keep Zod validation in `app/schemas/`; keep feature-private components in a page's `_components/`.

## API Contracts

Catalog and image clients are generated by sibling `ecommerce-*-service-api` repositories. Never
edit their `gen/typescript` output: change the owning `.proto` and run that API repo's
`make generate`. Use `pnpm link:local` only for cross-repository API development.
